## Arc differences that actually affect a facilitator

Arc targets Ethereum's **Osaka** hard fork and ships EIP-7708 ahead of upstream. Most of it is transparent to application code. These five are not.

**USDC is the native gas token, at 18 decimals natively and 6 through its ERC-20 interface** — one balance, two views, a factor of 10<sup>12</sup> apart. See [supported assets](/docs/supported-assets) for what that breaks if you get it wrong.

**The minimum base fee is 20 gwei, and a transaction below it is silently dropped.** Not rejected — dropped. The mempool discards a transaction whose `maxFeePerGas` is under 20 gwei, producing no error, no receipt, and no block inclusion. If you are building your own settlement path, never hardcode a fee below this, and prefer your library's fee estimation (viem currently returns 24–29 gwei here). The base fee is paid to the block beneficiary rather than burned.

**The blocklist is enforced at runtime.** A value transfer to or from a blocklisted address reverts — and an included transaction that reverts on the blocklist check still consumes gas. This is why we re-simulate inside `/settle` rather than trusting verification: a reverting payment is better turned into a verdict than a bill. See [how it works](/docs/how-it-works).

**Finality is deterministic and instant.** A transaction finalizes on inclusion, so one confirmation is final and there is no reorg to wait out. Our confirmation timeout is 10s, which at ~0.51s blocks is headroom for a slow RPC rather than for consensus.

**`eth_getLogs` is capped at 10,000 blocks** and returns error `-32012` past that — about 85 minutes of history per call. Separately, the primary endpoint is load-balanced across backends at slightly different heights, so a read at the chain head can return `-32014`; back off briefly and retry rather than treating it as a failure.

Also, for completeness: `PREVRANDAO` always returns `0` (no on-chain randomness), blob transactions are rejected, the EIP-4788 beacon-roots contract is absent, and native value transfers to the zero address or to a self-destructed account revert as forbidden burns. None of these touch an EIP-3009 transfer.

**There is no wrapped USDC address on Arc.** On other EVM chains a protocol deploys a WETH-style wrapper to give the native asset an ERC-20 interface; on Arc the native USDC already satisfies `IERC20`, so that step does not exist. If you are looking for a `WUSDC`, you want `0x3600…`.

We do not use the Permit2 path — the allowlisted asset is natively EIP-3009 — but it is listed because it is deployed and StableFX requires it.

See Arc's own [contract addresses reference](https://docs.arc.io/arc/references/contract-addresses) for the full set, including USYC and the ERC-8004 reputation and validation registries.

## Adding the chain to viem

viem ships Arc, so there is nothing to define:

```ts
import { arc, arcTestnet } from "viem/chains";
```

Both carry `nativeCurrency: { name: "USDC", symbol: "USDC", decimals: 18 }` — the native view, which is correct for `getBalance` and `formatEther`. Payment amounts remain 6-decimal.

If you need the chain by hand anyway:

<NetCode filename="chain.ts">
{`import { defineChain } from "viem";

export const arc = defineChain({
  id: {{chainId}},
  name: "{{networkName}}",
  // 18 is the native interface. The same USDC reads 6 decimals as an ERC-20.
  nativeCurrency: { name: "USDC", symbol: "USDC", decimals: 18 },
  rpcUrls: { default: { http: ["{{rpc}}"], webSocket: ["{{wsRpc}}"] } },
  blockExplorers: { default: { name: "Arc Explorer", url: "{{explorer}}" } },
  testnet: {{network}} === "testnet",
});`}
</NetCode>

## Explorer APIs

Both explorers are Blockscout, so the v2 JSON API is available and useful for building your own views:

<NetCode lang="bash">
{`# Chain stats — average block time, gas price bands
curl -s '{{explorer}}/api/v2/stats' | jq

# Verified source and ABI for any contract
curl -s '{{explorer}}/api/v2/smart-contracts/{{asset}}' | jq '.name, .abi'

# Transactions for an address — e.g. our facilitator signer
curl -s '{{explorer}}/api/v2/addresses/0xSigner/transactions' | jq`}
</NetCode>

That last one is how you can audit our gas spending independently of the figures we report. Note that the mainnet explorer sits behind a bot challenge, so a bare `curl` may get an interstitial where the testnet one returns JSON; use a browser or a real user agent.
